시작하기

플랫폼을 선택하세요

iOS와 Android 모두 동일한 기능을 제공합니다.

iOS
iOS 17+
1

소스 클론

GitHub에서 소스를 받아 Xcode로 빌드 후 iPhone에 설치합니다.

2

BYD 계정 로그인

설정 탭에서 BYD 공식 앱 계정(이메일·비밀번호)을 입력합니다.

3

자동 수집 시작

차종·요금 설정 후 5분마다 차량 데이터를 자동 수집합니다.

GitHub에서 소스 받기 →
🤖
Android
Android 8.0+
1

APK 다운로드

아래 버튼으로 최신 APK를 받고, 알 수 없는 앱 설치를 허용한 뒤 실행합니다.

2

BYD 계정 로그인

설정 탭에서 BYD 공식 앱 계정(이메일·비밀번호)을 입력합니다.

3

자동 수집 시작

차종·요금 설정 후 5분마다 차량 데이터를 자동 수집합니다.

APK 다운로드
4

차종·요금 설정

보유 차종과 전기요금(원/kWh)을 입력하면 정확한 충전 비용과 전비가 계산됩니다.

5

충전·주행 자동 기록

충전과 주행 시작·종료를 자동 감지해 세션별로 이력에 기록됩니다.
