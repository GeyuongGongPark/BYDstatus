공식 앱이 보여주지 않는 것들

BYD 공식 앱의 빈틈을 채우는 데이터 분석 기능을 제공합니다.

📈
배터리 이력 그래프
시간대별 배터리 % 변화를 그래프로 확인. 충전 구간, 주행 구간, 주차 구간을 색상으로 구분. 24시간 / 7일 / 30일 필터 지원.
⚡
충전 세션 트래킹
충전 시작/종료 자동 감지. 충전량(kWh), 평균 충전 전력, 충전 시간, 추정 비용, 충전 위치를 세션별로 기록.
🚗
주행 세션 분석
주행 세션별 소비 에너지, 주행 거리, 전비(km/kWh) 기록. GPS 또는 수동 입력으로 정확한 전비 계산.
💰
월별 비용 통계
월별 충전 총량, 충전 횟수, 추정 전기 비용. 전년 동월 비교와 심야 요금제까지 고려한 정확한 비용 계산.
📊
대시보드
현재 배터리 %, 충전 상태, 오늘의 충전량과 주행 거리, 이번 달 누적 비용을 한눈에.
🔄
백그라운드 수집
앱이 꺼져있어도 BGAppRefreshTask로 데이터 수집 지속. 포어그라운드 5분 / 백그라운드 자동 폴링 병행.

사용법

시작하는 방법

설정 3단계만으로 바로 사용할 수 있습니다.

1

BYD 계정 입력

BYD 공식 앱에서 사용하는 계정(이메일/비밀번호)을 입력합니다. 한국 서버에 자동 연결됩니다.

2

차종 및 전기요금 설정

보유 차종과 전기요금 단가(원/kWh)를 입력합니다. 심야 요금제 시간대도 따로 설정 가능합니다.

3

데이터 수집 시작

앱이 자동으로 5분마다 차량 상태를 수집합니다. 충전·주행 세션이 자동으로 감지되어 기록됩니다.

4

통계 확인

배터리 이력, 충전 세션 목록, 주행 분석, 월별 비용을 대시보드에서 확인합니다.
